Setup
  1. Plug the FM-1 (running FM-106) into your computer with USB.
  2. Juno MIDI OUT → your MIDI interface's MIDI IN.
  3. On the Juno's back, set the MIDI function switch to III (sends sliders and patches).
  4. On FM-106's MIDI SETUP page, set PC IN to ON, so it follows the Juno's patch changes.
  5. If you also use FM-1 Mirror, set its Keys to None, or you'll hear every note twice.
  6. Pick both ports above, press Start. Move a slider on the Juno and watch FM-106 follow.

Patch changes load the Juno's exact settings live on FM-106; they never overwrite its saved presets. The Juno doesn't send patch names, so FM-106 shows its own name for the same preset number.
